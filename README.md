# Гонки дронов · Первенство России 2026 — графический пакет (CG)

HTML-графика для vMix (Web Browser input с альфа-каналом) и веб-пульт управления.
Данные берутся напрямую из судейской Google-таблицы: внесли значение — через 2–3 секунды оно в титре.

```
index.html     — графика эфира 1920×1080, прозрачный фон (в vMix как input)
control.html   — пульт: кнопки IN/OUT, превью, редактирование текстов и таблиц
server.js      — мини-сервер синхронизации (Node.js, без npm-зависимостей)
js/core.js     — разбор листов Google Sheets, имена, шина синхронизации
js/graphics.js — анимации и вёрстка титров
js/control.js  — логика пульта
demo/*.csv     — демо-данные для репетиции (вымышленные результаты!)
assets/        — логотип (вырезан из KV), ключевой визуал, шрифты Unbounded / Exo 2 (OFL)
```

## Быстрый старт

1. Установите [Node.js](https://nodejs.org) 18+ (LTS).
2. Скачайте репозиторий и запустите сервер:
   ```
   node server.js
   ```
   (на Windows — `start-server.bat`, на macOS — `start-server.command`: он ещё и не даёт Mac уснуть). По умолчанию порт **8787** (8088 занят веб-контроллером vMix).
3. **vMix** → Add Input → **Web Browser** → URL `http://localhost:8787/` , разрешение **1920×1080**.
   Фон страницы прозрачный — input ставится оверлеем поверх камер.
4. **Пульт** — в обычном Chrome: `http://localhost:8787/control.html`
   (с другого компьютера в сети — `http://IP-машины-с-vMix:8787/control.html`, адрес печатается при запуске).

> Если открыть `control.html` без сервера (например, с GitHub Pages), пульт работает в режиме «ЛОКАЛЬНО»:
> графика обновляется только во вкладках того же браузера. Для vMix нужен `server.js`.

## Схема «пульт на MacBook, vMix у режиссёра»

* Сервер и пульт работают на MacBook, vMix забирает графику по сети: Web Browser input → `http://IP-MacBook:8787/`.
* IP печатается при запуске сервера (или: Системные настройки → Сеть). Лучше кабель/один Wi-Fi и закреплённый IP (резервирование DHCP на роутере).
* При первом запуске macOS спросит «Разрешить входящие подключения для node» — **Разрешить**.
* Mac не должен засыпать (`start-server.command` использует `caffeinate`). Если Mac перезагрузится — графика в vMix переподключится сама и восстановит последнее состояние.

## Титры

| Титр | Размер / место | Поля |
|---|---|---|
| Стартовый титр (заглушка) | 1440×810 (75%), центр, ключевой визуал | плашка, строка 1, строка 2 |
| Геотитр | 650×100, низ-лево | город, дата |
| Нижняя подпись | 1400×120, низ | «Имя ФАМИЛИЯ», должность (список пресетов) |
| Квалификация ЛЗ | центр, высота строк подстраивается под кол-во | №, рейтинг региона, пилот, округ, время квал., место квал., место групп. |
| Полуфинал ЛЗ (группы 1, 2), Финал ЛЗ | центр | место, ранг, пилот, цвет, 1, 2, 3, доп., сумма |
| Квалификация КЗ | центр | №, рейтинг региона, пилоты, округ, круги квал., время квал., место квал., место групп. |
| Групповой этап КЗ (группы 1–4) | центр | место, пилоты, цвет, кол-во кругов, время, пит-стоп, время, место |
| Финал КЗ | центр | место, пилоты, канал, цвет, круги, время, дроны, питстопы |

Два независимых слоя: **центр** (стартовый титр / таблицы) и **низ** (геотитр / подписи) — можно показывать одновременно.
Смена титра в слое — автоматически: старый уходит (transition out), новый приходит (transition in).

## Данные из Google Sheets

Используются листы `75 ЛЗ М`, `75 ЛЗ Ж`, `75 КЗ М`, `75 КЗ Ж` (gid прописаны в настройках пульта).
Пульт читает CSV-экспорт листа (`/export?format=csv&gid=…`), поэтому **таблица должна быть доступна по ссылке на чтение**.

Разбор устойчив к сдвигам строк: блоки ищутся по заголовкам (`Место | Ранг | Пилот…`, `Место | ФИО…`, `Команда | ФИО…`),
этап и группа — по подписям над ними (`Полуфинал`, `Финал`, `ГРУППОВОЙ ЭТАП`, `Четвертьфинал`, `Группа N`).
Если судьи добавят группу или этап с такой же разметкой — он сам появится в списке титров.

* «Фамилия Имя Отчество» → **Имя ФАМИЛИЯ**; в командном зачёте — `Имя ФАМИЛИЯ | Имя ФАМИЛИЯ`.
* Строки-заглушки «х» пропускаются; ошибки формул (`#REF!` и т.п.) не выводятся.
* Лист, который в эфире или открыт в редакторе, опрашивается каждые 3 с, остальные — каждые 30 с (настраивается).

## Вход в пульт

`control.html` открывается только после ввода пароля (`login.html`). Галочка «Запомнить меня на этом ПК»
сохраняет вход в этом браузере; без неё вход действует до закрытия вкладки. Кнопка «Выйти» — в шапке пульта.
Графика (`index.html`) для vMix пароля не требует.

**Сменить пароль:** откройте `login.html?hash=1`, введите новый пароль — страница покажет его хэш.
Замените строку в `PASS_HASHES` в `js/auth.js` (можно указать несколько хэшей — по паролю на человека) и закоммитьте.
Сам пароль в коде не хранится, только хэш.

## Листы и таблицы

* В «⚙ Настройки → Листы в пульте» отмечаются нужные листы (75 / 200 / 330 / ТС). Класс, зачёт и категория
  берутся из самого листа (строка «КЛАСС 330 ЛИЧНЫЙ ЗАЧЁТ», «ЮНИОРЫ/ЮНИОРКИ») — в пульте «330 ЛЗ М · Личный зачёт · Юниоры»,
  в титре «Класс 330 · Личный зачёт · Юниоры».
* Состав титров в пульте строится по таблице: «Общая таблица», «Квалификация · Группа N», «Полуфинал · Группа N», «Финал».
  Таблица, в которой ещё нет ни одного пилота, в пульте не показывается — появится сама, как только судьи её заполнят.
* Пустые ячейки, «х» и нулевые заготовки формул («0», «0,00») в эфир не выводятся; полностью пустые колонки скрываются
  (галочка «скрывать пустые колонки» в редакторе таблицы).
* Цвет пилота показывается только цветной плашкой, без подписи.

## Ручное редактирование

* Все текстовые поля титров редактируются в пульте и сразу применяются (в том числе к титру в эфире).
* В таблицах любую ячейку можно исправить — правка подсвечивается жёлтым и имеет приоритет над Google-таблицей.
  Двойной клик по ячейке — вернуть значение из таблицы. Можно скрыть строку (👁) или колонку, задать свой заголовок,
  сортировку, число строк на странице и автолистание страниц.
* Настройки, правки и подписи хранятся в браузере пульта; **⚙ Настройки → Скачать .json** — резервная копия.

## Репетиция

В пульте переключите источник на **«Демо-данные»** — подгрузятся `demo/*.csv` с вымышленными результатами
(в шапке горит жёлтая плашка «ДЕМО-ДАННЫЕ»). Перед эфиром верните «Google Таблица».

## Запуск с GitHub Pages (облачный режим, без server.js)

1. Репозиторий на GitHub → **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
   Через 1–2 минуты сайт доступен по адресу `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.
2. Firebase: создать **Realtime Database** (Build → Realtime Database → Create Database, регион `europe-west1`, *locked mode*),
   во вкладке **Rules** вставить и нажать Publish:
   ```json
   { "rules": { "cg": { ".read": true, ".write": true }, ".read": false, ".write": false } }
   ```
3. Открыть пульт `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/control.html` → **⚙ Настройки → Связь**:
   режим «Облако: Firebase», адрес базы (`https://…-default-rtdb.europe-west1.firebasedatabase.app`), ключ комнаты (генерируется сам).
   Сохранить — в шапке загорится «СВЯЗЬ: FIREBASE».
4. Там же — **«Ссылка для vMix»**: скопировать и вставить в vMix (Web Browser input, 1920×1080).
   Ссылка содержит адрес базы и ключ комнаты: `…/?fb=…&room=…`.

Пульт можно открыть с любого компьютера: настройки хранятся в браузере, поэтому на новом компьютере
либо повторите шаг 3 с тем же ключом комнаты, либо перенесите настройки через «Скачать / Загрузить .json».
Локальный режим (`server.js`) продолжает работать — переключается там же.
