Листы в пульте

Отметьте листы, которые нужны в эфире. Название класса, зачёт и категория берутся из самого листа.

Связь пульта с графикой

В облачном режиме пульт и графику можно открывать с GitHub Pages с любых компьютеров с интернетом. Ключ комнаты — секрет: без него к титрам не подключиться.

Google-таблица

Таблица должна быть открыта по ссылке («Все, у кого есть ссылка — читатель»). gid — число после #gid= в адресе листа.

Резервная копия настроек пульта

Тексты титров, нижние подписи, ручные правки и настройки таблиц.
